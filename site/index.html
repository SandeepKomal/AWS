Practise on a real account, safely

A sandbox with a budget

Use a separate account for labs, sign in with IAM Identity Center, and set a budget alert before you create anything.

# 1. Sign in (once per day)
aws configure sso
aws sso login --profile sandbox

# 2. Check where you are
aws sts get-caller-identity --profile sandbox

# 3. Get the course
git clone https://github.com/SandeepKomal/AWS.git

Clean up when you are done

NAT gateways, load balancers, Elastic IPs, databases and volumes bill by the hour. Delete stacks, then check nothing is left.

aws cloudformation delete-stack --stack-name lab-vpc
aws ec2 describe-nat-gateways --query 'NatGateways[?State==`available`]'
aws ec2 describe-addresses
aws ec2 describe-volumes --filters Name=status,Values=available
