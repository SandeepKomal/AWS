# Contributing

Contributions that make the AWS examples safer, clearer, and more reproducible are welcome.

Useful contributions include:
- Corrected CloudFormation templates
- New AWS service examples
- AWS CLI examples
- Troubleshooting guides
- Security and least-privilege patterns
- Cost-optimization examples

Before opening a pull request:
1. Test templates where practical.
2. Remove account-specific IDs and secrets.
3. Document the AWS Region and prerequisites.
4. Explain what the example teaches.
